# «Полезные люди» — Йошкар-Ола: главная страница (прототип для согласования)

Jeywa Studio. Адаптивная главная на основе выбранного клиентом варианта №4 и семи правок из последнего письма. Это статический прототип: backend, каталог, админка и MAX — следующие этапы.

## Запуск

Обычный статический сайт без сборки: `index.html` открывается двойным кликом или через любой локальный сервер.

```bash
npm run serve        # http://localhost:5180 (необязательно, можно открыть index.html напрямую)
```

Вариант первого экрана: `index.html?hero=house` / `index.html?hero=city`.

## Структура

```
index.html                вся страница — правится напрямую
assets/app.css            готовый CSS (Tailwind + свои стили)
assets/js/main.js         интерактив без библиотек (меню, hero B, карусель, формы, диалоги)
assets/img/brand/         знак логотипа, favicon, icon-192, apple-touch-icon
assets/img/photos/        фото WebP + credits.json (авторы и лицензии)
tailwind.input.css        исходник стилей: токены (:root), компоненты, анимации
brand-source/             исходники логотипов клиента, на сайт не попадают
```

## Если меняете стили

`assets/app.css` уже собран и содержит все классы, которые есть в `index.html`. Если добавляете в HTML новый Tailwind-класс, которого раньше не было, или правите `tailwind.input.css`, пересоберите CSS одной командой:

```bash
npm install          # один раз
npm run css          # или npm run css:watch — пересборка при каждом сохранении
```

## Как отражены правки клиента

| № | Правка | Где |
|---|---|---|
| 1 | Нет аренды и «Снять» | поиск без табов аренды, услуги без аренды |
| 2 | Круглая кнопка обратного звонка | `partials/callback.html`: своя кнопка + диалог, скрывается у формы консультации и в подвале. «Консультация» в шапке сохранена (решение за клиентом) |
| 3 | Направления с фото под поиском, «Бани» | `partials/categories.html`: тёмный блок, 5 направлений |
| 4 | Иконки преимуществ на чёрном, ближе к команде | `partials/advantages.html` перед «О нас» |
| 5 | Карусель фото + выбор агента вместо федеральных цифр | `partials/about.html` |
| 6 | Hero с Йошкар-Олой и лёгким движением | вариант «Йошкар-Ола вечером»: реальная набережная, окна плавно загораются и гаснут (текстура соседних окон этого же кадра), часы на башне показывают текущее время. Кнопка паузы, при reduced motion — статичный кадр |
| 7 | Подборка объектов через админку | `featured-objects.json`: в подборку попадают только `featured: true` по `sort_order`; в рабочей версии — флаг и порядок в Filament |

## Оживление фото первого экрана

Облака на фото дома медленно плывут. Небо выделено маской по силуэту здания (`assets/img/photos/hero-yo-sky-mask.png`), поверх фото слой «подложки неба» (`hero-yo-sky-*.webp`, здание залито цветом неба) уплывает вправо на 13% ширины фото и возвращается (10 с в каждую сторону), только `transform`. Совмещение слоя с фото проверено попиксельно на 375–1920px. Кнопка паузы убрана по просьбе заказчика (это отступление от WCAG 2.2.2); вне экрана анимация стоит, при `prefers-reduced-motion` — статичное фото. Свет в окнах и часы не делались: на дневном зимнем фото окна без света, часов в кадре нет.

## Что временно и требует материалов клиента

- Телефон, адрес, часы работы — заглушки `XX-XX-XX` / «уточняется».
- Верхняя строка шапки: часы работы — **демо** (тот же график в футере); Telegram и MAX — заглушки до получения аккаунтов, значок MAX — нейтральная иконка до официального SVG.
- Логотип — знак из аватара VK клиента + название текстом; для продакшена нужен SVG.
- Цвета и шрифт — рабочее приближение (брендбука нет): зелёный `#63B54B`, графит `#161A17`, шрифт Inter (как на helpfulpeople.ru).
- Фото команды — временные фото переговорных (помечены на странице).
- Объекты, цены, адреса — демо (помечены), районы в поиске — до справочника из CRM.
- Ссылки на разделы следующих этапов открывают честную заглушку, а не битую страницу.
- Фото — Wikimedia Commons (CC0 / CC BY / CC BY-SA), авторы в `assets/img/photos/credits.json`. Для продакшена лучше собственные фото или купленный сток.

## Проверено

Ширины 375 / 768 / 1024 / 1280 / 1440, оба варианта hero: без горизонтальной прокрутки и ошибок консоли. Клавиатура и фокус, Esc и возврат фокуса в диалогах, валидация и маска телефона, `prefers-reduced-motion`, пауза анимаций (WCAG 2.2.2).
